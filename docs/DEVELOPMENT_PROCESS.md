# Processo de desenvolvimento

Cada incremento entrega um comportamento observável, começa no teste do seam público e termina com evidência real. Commits são pequenos e reversíveis. Cada commit substantivo altera exatamente um Journal, que registra objetivo, decisão e comandos realmente executados.

ADRs registram somente decisões arquiteturais duráveis. O SDD ativo descreve o próximo estado pretendido; README e evidências descrevem o que já funciona. O gate local impede commits sem o Journal obrigatório.
